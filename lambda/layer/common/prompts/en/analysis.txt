Definitions of specific threat information:
- IoC: Specific IP addresses, domains, hashes, etc.
  - Information stating only "how many IPs were found" is NOT an IoC.
  - If there is no specific listing, it is NOT an IoC.
- IoA: Attack techniques, commands, methods, etc.
  - Only treat attack techniques/methods as IoA if they can be mapped to a MITRE ATT&CK Technique.
  - [IMPORTANT] Extract execution flows visible in image diagrams as IoAs using SPECIFIC filenames (e.g., "kira.ps1 -> SCRRC4ryku.vbe"). DO NOT use abstract placeholders like "FileA executes FileB"; use the actual observed filenames.
  - CVE numbers are NOT IoAs.
- Malware Behavior: Malware names, descriptions of behavior, etc.
